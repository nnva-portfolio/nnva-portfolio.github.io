# Van Anh — Portfolio

UI/UX & graphic design portfolio of Nguyen Ngoc Van Anh.

Static site, no build step. Open `index.html` in a browser.

## Pages

- `index.html` — Home / About (EN)
- `about-vi.html` — About (VI)
- `linkadz.html`, `linkadz-vi.html` — Case study 01 · LinkAdz
- `yumzy.html`, `yumzy-vi.html` — Case study 02 · YUMZY
- `designathon.html`, `designathon-vi.html` — Designathon 2025

## Folders

- `cover/` — project cover images
- `ds/` — LinkAdz design system boards + motion clip
- `fj/` — LinkAdz flow screens (before / after)
- `dt/` — Designathon images and prototype
- `yz/` — YUMZY screens, clips and brand
- `logo/` — logo and favicons
